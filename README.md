## 🏛️ Tentang HIRAETH
**HIRAETH** adalah website kelas yang berfungsi sebagai ruang digital untuk menyimpan memori, identitas, dan kreativitas bersama.

Didesain dengan konsep **Minimalist Modern Y2K**, website ini menggunakan:
- 🎨 **Dark charcoal theme** sebagai dasar
- ⚡ **Electric & neon blue accents** sebagai highlight
- 💻 Tampilan simpel, clean, dan fokus ke konten

Website ini bukan sekadar tampilan, tapi juga arsip digital kelas kami.
